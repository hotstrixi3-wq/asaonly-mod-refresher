# V3.78.2 — dynamiczny przycisk Importera

Plugin Importera deklaruje akcję głównego paska przez metadane. Uniwersalny PluginHost tworzy `IMPORTER KONFIGÓW` bez wpisywania nazwy importera w logikę głównego okna. Przycisk jest aktywny, gdy plugin jest ON, oraz natychmiast wyszarzany, gdy w Managerze ustawiono OFF. Ponowne ON natychmiast go aktywuje.

Mechanizm jest ogólny: kolejne zaufane pluginy mogą deklarować własne akcje głównego paska bez kolejnej dedykowanej przeróbki głównego klocka.

Testy automatyczne: 64/64 PASS.
