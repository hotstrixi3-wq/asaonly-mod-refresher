# V3.78 — Tester CPU i importer starych katalogów

## CPU 1.2.0

Panel ma trzy zakładki:

1. `SERWERY` — dotychczasowy rzeczywisty odczyt i egzekwowanie priority/affinity.
2. `TOPOLOGIA CPU` — model, liczba rdzeni fizycznych i logicznych oraz mapa numerów affinity, bez obciążenia.
3. `TESTER CPU` — ręczny szybki lub dokładny pomiar każdego logicznego CPU.

Tester przypina wyłącznie własny wątek roboczy kolejno do logicznych CPU. Nie modyfikuje procesów serwerów. Ma potwierdzenie, postęp i przerwanie. Wynik pokazuje ranking względny i dzieli zmierzone CPU pomiędzy aktywne mapy. Przeniesienie propozycji ustawia tylko pola GUI zakładki SERWERY; nie włącza affinity i nie zapisuje go. Administrator musi sprawdzić propozycję, zaznaczyć Affinity oraz zapisać konkretny wiersz.

Maska affinity obsługuje teraz wieloelementowe wartości `CPU 0,2,4,...`.

## Importer starych konfiguracji 1.0.0

Opcjonalny plugin, domyślnie ON, ponieważ przydaje się przy pierwszym uruchomieniu i odzyskiwaniu starej konfiguracji. Samo ON nie uruchamia skanowania w tle. Gdy wszystkie mapy są już skonfigurowane, można go wyłączyć. Główny przycisk `Dodaj mapę` pozostaje, natomiast stary przycisk importu pojedynczego pliku usunięto z głównego okna.

Importer przyjmuje główny katalog starego Refreshera, rekurencyjnie i tylko do odczytu skanuje JSON-y, rozpoznaje konfiguracje pojedynczych map i stare konfiguracje globalne, rozbija globalne serwery na mapy, grupuje rotowane backupy, wybiera najnowszy prawidłowy plik, wykrywa sekrety RCON bez wyświetlania hasła, pokazuje checkboxy i importuje dopiero po potwierdzeniu. Uszkodzony JSON nie blokuje pozostałych wyników. Źródło nie jest zmieniane.

## Walidacja użytkownika i administratora

- pełna flota jednostkowa/integracyjna/symulacyjna: **62/62 PASS**;
- fuzz skanera na 100 losowych drzewach katalogów: **100/100 PASS**;
- kontrola niezmienności katalogu źródłowego: PASS;
- stare konfiguracje globalne rozbijane na mapy: PASS;
- najnowszy backup z rotacji wybierany deterministycznie: PASS;
- uszkodzone i obce JSON-y izolowane: PASS;
- sekret wykrywany bez prezentowania wartości: PASS;
- trzy serwery / 24 CPU otrzymują po osiem unikalnych CPU w propozycji: PASS;
- brak aktywnych serwerów nie tworzy niebezpiecznej propozycji: PASS;
- zgodność dotychczasowych zasad restartów, RCON i wersji modów: PASS.

Rzeczywiste rozpoznanie Windows, wygląd nowych zakładek i wyniki benchmarku wymagają testu na komputerze użytkownika; sandbox nie udostępnia Windows API ani jego procesora.
