# V3.80.18 — przeniesienie RCON z zakładek map do wymaganego pluginu

## Cel

RCON jest jednym z trzech podstawowych obowiązków programu. Plugin RCON nie jest opcjonalną konsolą administracyjną: przejmuje konfigurację połączeń, mapowe procedury czasowe i ręczne komendy, które wcześniej zajmowały zakładki map.

## Zmiany

- Zakładki map nie budują kontrolek adresu, portu, hasła, testu RCON, linii procedury, konsoli ani schowka komend.
- `PLUGINY/86_rcon_admin.py` jest wymaganym modułem z głównym przyciskiem `RCON`.
- Panel posiada osobną stronę dla każdej mapy i obsługuje połączenie, test `ListPlayers`, do 20 lokalnych linii oraz ręczną komendę z potwierdzeniem.
- Istniejące pola konfiguracji map pozostają zgodne; migracja nie zmienia czasów ani komend. `205 → DoExit` pozostaje lokalnym czasem 205 sekund.
- Pusta włączona linia jest ignorowana, a linia częściowo wypełniona pozostaje błędem.
- Cały panel jest walidowany przed zapisem; nieprawidłowa mapa nie powoduje częściowego zapisu wcześniejszych map.
- Wspólne porty aktywnych map są blokowane.
- Zmiana procedur podczas aktywnej procedury jest blokowana.
- Brak wymaganego pluginu zatrzymuje wykonanie przed wysłaniem RCON i przed przygotowawczymi zapisami procedury.
- Backend kolejki pozostaje izolowany per mapa, aby monitoring i koordynator mogły bezpiecznie wysyłać komendy poza wątkiem Tk.

## Walidacja

- test architektoniczny potwierdza brak edytora i konsoli RCON w `_build()` zakładki mapy;
- test pluginu potwierdza status wymagany, główną akcję i obsługę 20 linii;
- dotychczasowe testy kwalifikacji map, lokalnych czasów, `DoExit`, sekwencyjności, READY i wersji po nowym procesie pozostają aktywne.
