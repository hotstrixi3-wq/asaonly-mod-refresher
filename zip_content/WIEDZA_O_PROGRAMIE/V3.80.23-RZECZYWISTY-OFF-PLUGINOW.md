# V3.80.23 — rzeczywisty OFF pluginów

V3.80.22 filtrowała diagnostykę według zapisanego OFF, ale nie wymuszała zgodności stanu wykonawczego. To mogło ukryć niespójność.

V3.80.23 wprowadza jeden autorytatywny stan efektywny w hoście pluginów. Zapisane OFF:

- wymusza `set_enabled(False)` przy wykryciu niespójności;
- blokuje `tick`;
- blokuje hooki;
- blokuje zdarzenia subskrybowane przez plugin;
- pokazuje OFF w Managerze i wyłącza zależne przyciski;
- usuwa plugin z diagnostyki i jej cache;
- nie powtarza w pętli próby wymuszania OFF przy wadliwym pluginie.

Test regresyjny celowo używa wadliwego pluginu, który ignoruje `set_enabled(False)`. Host mimo tego nie pozwala mu wykonać pracy, hooku ani zdarzenia. Osobny test ponownego uruchomienia sprawdza rzeczywiste `is_enabled() == False` dla wszystkich opcjonalnych pluginów produkcyjnych oraz brak diagnostyki i logów.
