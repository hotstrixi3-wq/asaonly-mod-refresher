# V3.79.2 — awaryjna naprawa crasha Drag & Drop

Natywna podmiana Windows WndProc w oknie Tkinter została całkowicie usunięta. W teście terenowym upuszczenie katalogu zakończyło cały proces Refreshera poza obsługą wyjątków Pythona. Stabilność programu ma pierwszeństwo.

Importer zachowuje skan całego katalogu wybranego przyciskiem, wykrywanie map, sekretów RCON i klucza CurseForge API oraz selektywny import. Klucz API pozostaje ukryty i ma osobny checkbox.

Dodano test regresji, który blokuje obecność `SetWindowLongPtr`, `WNDPROC` i `DragAcceptFiles` w importerze. Flota: **68/68 PASS**.

Drag & Drop może wrócić wyłącznie przez sprawdzoną bibliotekę DnD z testem na podniesionym procesie Windows; nie przez ręczne przejęcie procedury okna Tk.
