# V3.80.35 — diagnostyka nie używa zniszczonych widgetów

Po zmianie języka drzewo Tk jest niszczone, lecz host zachowywał `manager_rows` ze wskaźnikami do usuniętych etykiet. Ścieżka OFF próbowała bez osłony ustawić `—` i powodowała `TclError: invalid command name`.

`stop_all()` usuwa teraz wszystkie wiązania starego UI. Diagnostyka dodatkowo traktuje martwy widget jako warstwę prezentacji do odrzucenia, nie jako błąd działania pluginu. Testy wstrzykują widget zgłaszający błąd i sprawdzają pełne czyszczenie lifecycle.
