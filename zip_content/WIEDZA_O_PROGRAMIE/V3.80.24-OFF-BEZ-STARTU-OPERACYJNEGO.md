# V3.80.24 — plugin OFF nie przechodzi przez start operacyjny

Host rozdziela bezpieczne przygotowanie konfiguracji (`prepare`) od aktywacji. Opcjonalny plugin z zapisanym OFF nie otrzymuje operacyjnego `start`, nie trafia do `_active`, nie otrzymuje ticków, hooków, zdarzeń ani diagnostyki. Plugin bez `prepare` pozostaje całkowicie niezainicjalizowany.

Wszystkie produkcyjne pluginy opcjonalne mają jawne przygotowanie bez uruchamiania pracy operacyjnej. Włączenie w Managerze najpierw przygotowuje plugin, następnie aktywuje cykl i zapisuje ON. Wyłączenie zapisuje OFF, wykonuje opcjonalne `deactivate` i usuwa plugin ze zbioru aktywnych.

Regresja celowo definiuje plugin, którego `start` oznacza uruchomienie workera; przy zapisanym OFF licznik wywołań pozostaje zerowy.
