# V3.80.19 — plugin RCON właścicielem transportu

V3.80.18 przenosiła interfejs, ale pozostawiała kolejki i transport w `ServerTab`. Ten podział był niepełny.

V3.80.19 przenosi do wymaganego pluginu RCON:

- kolejki osobne dla map;
- workery wysyłające poza wątkiem Tk;
- trzy próby z opóźnieniem;
- czyszczenie kolejek przy anulowaniu;
- walidację i udostępnianie procedur;
- test połączenia oraz ręczne wysyłanie.

`ServerTab` zachowuje wyłącznie dane potrzebne do zgodnego zapisu istniejącego formatu konfiguracji. Nie zawiera interfejsu RCON, klienta sieciowego, kolejki, workera ani metod wysyłania i walidacji RCON. Monitoring i koordynator korzystają z API wymaganego pluginu.

Brak pluginu w rzeczywistym hoście zatrzymuje automatyczną procedurę. Fallback obecny w `ProcedureMixin` służy wyłącznie izolowanym symulacjom bez uruchamiania hosta pluginów.
